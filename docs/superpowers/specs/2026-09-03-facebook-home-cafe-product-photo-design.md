# Facebook 홈카페 제품 사진 게시물 디자인

## 목표

스킨케어가 아닌 고가 생활가전으로 제품군을 확장하고, 단순 실내 사진보다 감정과 상황이 분명한 배경으로 Facebook 피드의 관심을 유도한다. 쿠팡에서 현재 검색 상단에 노출된 `드롱기 마그니피카S 전자동 커피머신 + 연수필터`를 사용한다. 완성 이미지와 게시 문안을 먼저 검토받고, 별도 승인 전에는 Facebook에 게시하지 않는다.

## 제품

- 상품명: 드롱기 마그니피카S 전자동 커피머신 + 연수필터
- 모델: ECAM22.110.SB
- 조회 가격: 609,000원
- 조회 상태: 로켓배송
- 상품 ID: 6643477611
- 가격, 재고, 배송 상태는 제작 시점과 게시 직전에 다시 확인한다.

## 이미지 콘셉트

- 형식: 세로 4:5, 1080×1350 PNG
- 배경: 빗방울이 맺힌 큰 창이 보이는 따뜻한 주방 또는 다이닝 공간
- 시간: 흐린 아침, 실내에는 따뜻한 간접조명과 자연광이 함께 있음
- 인물: 명확한 성인 한국인 모델 한 명
- 행동: 갓 추출한 에스프레소 잔을 들고 향을 즐기며 편안하게 웃는 순간
- 관심 요소: 창문의 빗방울, 커피 증기, 따뜻한 조명, 나무 카운터의 질감
- 제품: 실제 쿠팡 제품 이미지를 카운터 위에 합성한다. 제품 크기는 모바일에서도 즉시 식별되도록 화면 너비의 약 25%로 한다.
- 훅: `매일 카페 가는 사람이라면?`
- 훅 위치: 얼굴과 제품을 가리지 않는 상단의 어두운 여백
- 제외: 제품 정보 카드, 다중 스펙, 가격 배지, 과도한 소품, 생성된 브랜드 글자, 워터마크

## 제작 방식

1. AI로 인물, 비 오는 창, 주방, 커피잔과 증기가 있는 텍스트 없는 장면을 생성한다.
2. 생성 장면에는 커피머신이나 브랜드 로고를 만들지 않는다.
3. 쿠팡에서 받은 실제 드롱기 제품 이미지를 배경 제거 후 카운터에 합성한다.
4. 장면의 광원에 맞춰 제품 색온도와 접촉 그림자를 조정한다.
5. 한글 훅은 로컬 Pillow 렌더러로 정확히 추가한다.

첫 줄에는 링크만 배치한다. 내부 관리 마커와 해시태그 묶음은 넣지 않는다.

## 검증

1. 상품명, 모델, 가격, 이미지, 링크가 같은 옵션인지 확인한다.
2. 1080×1350 원본과 360×450 모바일 미리보기를 만든다.
3. 모바일 미리보기에서 인물의 표정, 비 오는 창, 제품, 훅이 각각 식별되는지 확인한다.
4. 제품 주변에 흰색 배경이나 합성 테두리가 남지 않았는지 확인한다.
5. 문안 첫 줄이 쿠팡 링크인지 확인한다.
6. 제휴 고지와 AI 이미지 고지가 포함됐는지 확인한다.
7. 완성본을 사용자에게 보여주고 게시 승인을 받은 뒤에만 Facebook API를 실행한다.
