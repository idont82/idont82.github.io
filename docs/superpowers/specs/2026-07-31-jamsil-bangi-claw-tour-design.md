# 잠실역 방이먹자골목 인형뽑기 코스 설계

## 목표

잠실역에서 방이먹자골목으로 들어가 실제 촬영한 6개 매장을 순서대로 둘러보는 블로그 글을 만든다. `blog/hongdae-claw-tour.html`의 생활형 코스 구조를 따르면서, 사진 EXIF 좌표와 웹에서 확인한 공개 정보를 분리해 신뢰할 수 있는 현장 기록으로 작성한다.

## 대상 매장과 동선

2026년 7월 25일 촬영 사진 40장의 EXIF 위치와 촬영 시간을 기준으로 아래 순서를 사용한다.

1. 캐치팡 프리미엄
2. 미션클리어 방이점
3. 캑티 가챠샵 방이점
4. 대빵오락실 방이점
5. 사격팡 방이점
6. Koala(코알라)

지도 좌표는 매장별 사진 묶음의 GPS 평균값으로 계산한다. 촬영 지점이 출입구와 내부에 걸쳐 있을 때에는 외관 사진 좌표를 우선한다. 매장 위치와 상충하는 이상치가 있으면 공개 주소와 대조한 뒤 외관 좌표를 사용한다.

## 정보 작성 원칙

- 매장명·주소·영업 상태는 공공 인허가 데이터, 매장 공식 채널, 지도 검색 결과 순으로 확인한다.
- 미션클리어 방이점은 서울 송파구 오금로11길 12, 대빵오락실 방이점은 오금로11길 16, 사격팡 방이점은 오금로11길 21, 코알라는 오금로11길 29를 공개 자료 기준 주소로 사용한다.
- 캐치팡 프리미엄과 캑티 가챠샵 방이점은 사진의 간판과 GPS를 기준으로 식별하고, 주소가 복수 출처에서 일치할 때만 상세 주소를 싣는다.
- 영업시간은 현장 출입문 또는 최신 공식 채널에서 확인된 경우에만 표시한다. 확인되지 않으면 방문 전 지도에서 다시 확인하라는 안내를 넣는다.
- 평점, 당첨 확률, 집게 힘, 난이도는 검증할 수 없으므로 수치나 단정적인 표현을 사용하지 않는다.
- 현장 사진으로 확인할 수 있는 층 구성, 기계 유형, 가챠·이치방쿠지 취급, 카드 결제 표식 등의 특징만 서술한다.
- 글 하단에 정보 확인 기준일과 영업 정보 변동 가능성을 명시한다.

## 페이지 구조

새 페이지는 `blog/jamsil-bangi-claw-tour.html`로 만든다.

1. 잠실역 출발 위치와 방이먹자골목 진입 요약
2. 6개 매장 지도와 추천 도보 순서
3. 매장별 외관·내부 사진과 확인 가능한 특징
4. 대형 오락실, 가챠 중심 매장, 짧게 들르기 좋은 매장 비교
5. 처음 방문할 때의 예산·시간·영업시간 확인 팁
6. FAQ와 관련 서울 인형뽑기 글

헤더, 좌·우 사이드바, 광고 영역, 지도, 사진 카드, 관련 글은 홍대 코스 페이지의 구성과 공통 스타일을 재사용한다. 제목과 메타데이터에는 `잠실역 인형뽑기`, `방이먹자골목 인형뽑기`, `방이동 오락실` 검색 의도를 자연스럽게 반영한다.

## 데이터 구조

`data/jamsil.json`을 새로 만들고 다음을 포함한다.

- 잠실역 출구와 방이먹자골목 진입 순서
- 전체 도보 거리
- 6개 매장의 이름, 규모 구분, 주소, 설명, 추천 여부, 위도, 경도
- 확인된 경우에만 영업시간

`data/areas.json`의 `jamsil` 항목은 `Coming Soon` 상태에서 실제 6개 매장 코스로 갱신한다. 블로그 지도는 기존 `data-area-map="jamsil"` 로더를 재사용한다. 지도 로딩 문구에 남아 있는 홍대 전용 표현은 지역 공통 문구로 바꾼다.

## 이미지 처리

- `blog/images/jamsil/original/`의 원본 40장은 수정하거나 커밋하지 않는다.
- 매장별 외관 1장과 내부 특징 사진 1~2장을 선별한다.
- 게시용 이미지는 `blog/images/jamsil/` 아래에 의미 있는 소문자 하이픈 파일명으로 저장한다.
- 일반 본문 사진은 원본 비율을 유지하고 긴 변을 최대 1600px로 축소한 JPEG로 만든다.
- JPEG 품질은 육안 품질과 용량을 비교해 약 82를 기본값으로 사용한다.
- 회전 방향은 EXIF Orientation을 반영해 픽셀에 적용한다.
- 게시용 파일에서는 GPS와 기기 정보를 포함한 EXIF 메타데이터를 제거한다.
- 대표 이미지, OG 이미지, 목록 썸네일은 같은 외관 사진에서 각각 필요한 비율로 중앙 크롭하되 간판이 잘리지 않도록 위치를 조정한다.
- 사진 속 방문자 얼굴이 식별 가능하게 크게 보이는 이미지는 사용하지 않거나 얼굴이 포함되지 않도록 크롭한다.

## 검색 노출과 연결

- canonical, Open Graph, Twitter Card, BlogPosting JSON-LD를 포함한다.
- 글 내부에서 서울 인형뽑기 가이드와 잠실새내 코스를 연결한다.
- `sitemap.xml`과 블로그 홈 연결은 현재 사용자 작업을 보존하면서 잠실 글 항목만 추가한다.
- `data/areas.json`을 통해 전체 인형뽑기 가이드에서도 잠실 지역을 실제 코스로 노출한다.

## 테스트와 검증

- 새 테스트에서 페이지 메타데이터, 6개 매장명, 지도 데이터, 사진 경로, 관련 링크를 확인한다.
- `data/jamsil.json`의 좌표와 주소, `data/areas.json`의 6개 매장 표시를 검증한다.
- 게시용 이미지의 최대 크기, 용량, EXIF GPS 제거 여부를 검사한다.
- 로컬 서버에서 데스크톱과 모바일 너비로 지도, 사진, 광고, 사이드바와 페이지 오버플로를 확인한다.
- 외부 주소와 영업시간은 구현 시점에 다시 조회해 확인 날짜를 기록한다.
