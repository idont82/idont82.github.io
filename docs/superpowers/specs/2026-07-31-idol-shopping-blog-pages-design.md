# 아이돌 쇼핑 블로그 5종 디자인

## 목표

최근 검색 관심도가 높은 아이돌 중 쿠팡에서 공식·라이선스 상품이나 안전한 범용 팬용품을 연결할 수 있는 5팀을 골라, 기존 공연 준비물 글과 겹치지 않는 구매 가이드 5개를 만든다.

## 선정 대상

| 팀 | 신규 글 | 핵심 구매 의도 |
|---|---|---|
| BTS | 타이니탄 굿즈 가이드 | 라이선스 생활·문구 굿즈 |
| 세븐틴 | 포토카드 바인더 가이드 | 공식 카드와 범용 보관용품 |
| 아이브 | 앨범·포토카드 가이드 | 앨범 버전과 특전 구성 |
| 에스파 | 시즌그리팅·앨범 가이드 | 고가 시즌그리팅과 앨범 비교 |
| 블랙핑크 | 앨범·포토카드 보관 가이드 | 기존 응원봉 글과 분리된 수집·보관 |

네이버가 전체 실시간 인기검색어 순위를 공개하지 않으므로 “네이버 검색 1위”처럼 검증할 수 없는 표현은 쓰지 않는다. 최근 아이돌 관심도 자료, 실제 검색 의도, 쿠팡 파트너스 API의 검색 결과 적합도를 교차해 주제를 선정했다고 밝힌다.

## 콘텐츠 원칙

- 각 글은 한 개의 H1, 고유한 제목·설명·canonical URL을 가진다.
- `BlogPosting` JSON-LD와 Open Graph 메타데이터를 제공한다.
- 공식·라이선스·범용 보관용품을 구분하고 비공식 여부를 단정하지 않는다.
- 쿠팡 상품은 확인일과 검색 순위를 밝히고 가격·구성 변동 가능성을 안내한다.
- 모든 제휴 링크에 `rel="sponsored nofollow"`와 파트너스 고지를 넣는다.
- 상품 나열보다 “누구에게 맞는가”, “무엇을 확인해야 하는가”를 먼저 설명한다.
- 기존 `/blog/assets/style.css`와 `/blog/assets/blog.js`를 재사용해 데스크톱·모바일 구조를 맞춘다.

## 파일 구조

- `data/idol-shopping-blog-pages.json`: 5개 글의 문구, 근거, 상품 데이터
- `scripts/generate-idol-shopping-blog-pages.js`: 공통 레이아웃으로 정적 HTML 생성
- `blog/<slug>.html`: 최종 게시 페이지 5개
- `tests/idol-shopping-blog-pages.test.js`: SEO, 고지, 상품 구분, 인덱스·사이트맵 검증
- `index.html`: 신규 글 카드 또는 링크
- `sitemap.xml`: 신규 canonical URL

## 검증

`node --test tests/idol-shopping-blog-pages.test.js`로 페이지 수, SEO 메타데이터, JSON-LD 파싱, 제휴 고지, 공식성 주의문, 모바일 광고, 우측 사이드바, 인덱스·사이트맵 노출을 확인한다.
