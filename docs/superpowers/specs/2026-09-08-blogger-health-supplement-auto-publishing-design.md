# Blogger 건강식품 자동 공개 설계

## 목표

Gold Pick Blogger(`https://goldpick-choice.blogspot.com/`)에 현재 쇼핑 수요가 확인되는 건강식품 한 개를 선정해 검색형 정보 글을 만들고 즉시 공개한다. 최초 Google OAuth 승인 이후에는 상품 조사, 글 생성, 중복 확인, 공개, 원격 검증을 한 명령으로 반복할 수 있게 한다.

## 확정된 편집 원칙

- Blogger 게시물은 초안이 아니라 생성 즉시 공개한다.
- 실제 섭취하지 않은 제품을 직접 먹어본 것처럼 서술하지 않는다.
- 공개 구매 후기에서 반복적으로 확인되는 평가를 `구매 후기에서 자주 언급되는 점`으로 요약한다.
- AI 작성 표시는 넣지 않는다.
- 질병의 예방·치료, 의학적 효과, 체중 감량 보장 등 검증되지 않은 건강 주장을 하지 않는다.
- 섭취량, 원료, 알레르기 및 주의사항은 선택된 상품의 공식 표시 정보에서 확인 가능한 범위만 사용한다.
- 쿠팡 링크와 게시 시점의 가격·배송 조건을 명시하고 변동 가능성을 알린다.
- 본문은 이미지 3장을 포함해 모바일 화면 약 3스크롤 분량으로 작성한다.
- 쿠팡 파트너스 고지는 본문 최하단에 다음 문구로 표시한다.

  > 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

## 제품 선정

1. 건강식품 후보 키워드를 소수의 일상 수요 범주로 제한한다. 초기 후보는 유산균, 오메가3, 종합비타민, 마그네슘이다.
2. 저장소의 쿠팡 파트너스 검색 도구로 현재 검색 결과를 수집한다.
3. 검색 상위 노출, 리뷰·평점처럼 API에서 실제 제공되는 신호, 로켓배송 여부, 판매자·상품명 일치 여부를 확인한다.
4. `인기 1위`, `최고`, `효과 보장`처럼 증명할 수 없는 표현은 사용하지 않는다.
5. 파일에 제품 ID, 정확한 상품명, 가격, 링크, 이미지 URL, 조사 시각과 근거를 보존한다.

초기 자동 공개는 한 상품만 대상으로 한다. 상품 선택 로직이 충분히 검증되기 전에는 일일 예약 발행을 추가하지 않는다.

## 글 구조

1. 60자 이내의 구체적인 검색형 제목
2. 특정 건강 문제를 진단하지 않는 일상적 구매 고민
3. 제품명과 공식 표시 정보에 근거한 주요 구성
4. 공개 구매 후기에서 반복되는 장점과 아쉬운 점
5. 구매 전에 확인할 대상·섭취 방법·주의사항
6. 게시 시점 가격, 구성, 배송 정보와 쿠팡 상품 링크
7. 가격·할인·배송 조건 변동 안내
8. 최하단 쿠팡 파트너스 고지

본문은 Blogger API가 받는 안전한 HTML로 생성한다. 제목은 본문 안에서 반복하지 않고 소제목은 `h2`, 목록은 `ul`, 외부 링크는 명확한 링크 텍스트와 `rel="nofollow sponsored"`를 사용한다. 본문 텍스트는 공백을 포함해 1,500~2,000자를 목표로 하며, 이미지 3장을 도입부·중간·구매 체크 구간에 분산해 모바일에서 약 3스크롤 분량이 되도록 한다.

## 이미지 전략

Blogger API v3에는 게시물 삽입 기능은 있지만 별도의 이미지 업로드 리소스는 없다. 게시물마다 다음 3장의 이미지를 `images/blogger/<post-slug>/`에 생성하고 GitHub Pages로 먼저 공개한다.

1. 쿠팡 파트너스 API가 제휴 용도로 반환한 실제 상품 대표 이미지
2. 공식 표시 정보만 정리한 주요 구성·섭취 확인 카드
3. 공개 구매 후기에서 반복되는 장점·아쉬운 점과 구매 체크리스트 카드

세 이미지에는 각각 구체적인 대체 텍스트를 넣고 본문 내 관련 문단 바로 뒤에 배치한다. 가상의 인물이 직접 섭취하는 장면이나 실제 체험을 암시하는 이미지는 사용하지 않는다. 이미지 파일만 저장소에 추가하며 별도의 GitHub 블로그 HTML 페이지는 만들지 않는다.

발행 명령은 해당 게시물의 정확한 이미지 디렉터리만 스테이징·커밋·푸시한 뒤, 세 공개 URL이 모두 HTTP 200인지 확인한다. 이미지 공개에 실패하면 Blogger 글을 공개하지 않는다. Blogger 공개가 실패하면 이미 공개된 이미지 파일은 자동 삭제하지 않고 재시도에 재사용한다.

## 인증과 비밀정보

- 사용자가 Google Cloud Console에서 프로젝트를 만들고 Blogger API v3를 활성화한다.
- OAuth 동의 화면과 데스크톱 애플리케이션용 OAuth 클라이언트를 만든다.
- 최초 실행 때 브라우저에서 `https://www.googleapis.com/auth/blogger` 권한을 한 번 승인한다.
- OAuth 클라이언트 파일과 갱신 토큰은 `.blogger-artifacts/`에 저장하고 Git에서 제외한다.
- 토큰, client secret, 쿠팡 인증정보는 명령 인수·로그·커밋에 출력하지 않는다.
- API 키만으로는 글을 쓸 수 없으며 OAuth 2.0 인증을 사용한다.

## 구성 요소

### `scripts/blogger-oauth.js`

로컬 루프백 콜백을 사용해 최초 OAuth 승인을 진행하고 토큰을 안전하게 저장한다. 기존 토큰이 있으면 새 로그인을 요구하지 않는다.

### `scripts/blogger-api.js`

액세스 토큰 갱신, 블로그 URL로 blog ID 조회, 최근 글 조회, 게시물 삽입과 공개 결과 재조회 기능을 제공한다. 네트워크 오류는 제한적으로 재시도하고 인증 오류는 즉시 중단한다.

### `scripts/build-blogger-health-post.js`

검증된 상품 JSON을 받아 제목, 1,500~2,000자의 HTML 본문, 라벨과 3장 이미지의 데이터 모델을 생성한다. 원시 후기 문장을 복제하지 않고 반복 경향만 요약하며, 금지된 체험·치료 표현과 필수 고지를 검사한다.

### `scripts/render-blogger-health-images.py`

실제 상품 이미지와 검증된 텍스트 데이터로 3장의 모바일 친화적 이미지를 만든다. 카드 이미지는 제품과 직접 관련된 정보만 표시하며 과장된 효능 문구를 허용하지 않는다.

### `scripts/publish-blogger-health-post.js`

전체 흐름의 진입점이다. 입력 검증 후 동일한 상품 ID 또는 고유 마커가 최근 게시물에 있으면 새 글을 만들지 않는다. 이미지 3장만 정확히 스테이징·커밋·푸시하고 공개 여부를 확인한 다음 `posts.insert`를 `isDraft=false`로 호출한다. 반환된 URL을 다시 읽어 제목·본문 길이·이미지 수·최하단 고지·상품 링크가 일치하는지 확인한다. 결과는 비밀정보가 없는 publication JSON으로 기록한다.

### `.blogger-artifacts/`

OAuth 자격증명, 갱신 토큰, 조사 원본, 발행 준비 JSON, 발행 결과를 저장하는 로컬 전용 디렉터리다. 전체 디렉터리를 `.gitignore`에 추가한다.

## 데이터 흐름

1. 인기 건강식품 후보 검색
2. 한 상품 선택 및 표시 정보·후기 근거 검증
3. 1,500~2,000자 발행 준비 JSON과 이미지 3장 생성
4. 금지 표현·필수 고지·쿠팡 링크·HTML·이미지 수 검사
5. 게시물 이미지 디렉터리만 Git 커밋·푸시
6. 세 이미지 URL의 HTTP 200 확인
7. OAuth 토큰 갱신
8. Blogger URL로 blog ID 확인
9. 고유 마커로 중복 검사
10. 즉시 공개
11. 공개 글 재조회 및 검증
12. 공개 URL과 게시물 ID 저장

## 실패 처리

- 제품 정보나 주의사항의 근거가 부족하면 공개하지 않는다.
- OAuth 파일이나 갱신 토큰이 없으면 설정 방법을 안내하고 공개하지 않는다.
- Blogger API가 게시물 ID를 반환하지 않으면 실패로 기록한다.
- 이미지 3장 중 하나라도 생성·푸시·HTTP 검증에 실패하면 Blogger 공개를 시작하지 않는다.
- 공개 요청 결과가 불명확하면 최근 글에서 고유 마커를 먼저 찾아 중복 공개를 방지한다.
- 원격 검증이 실패해도 이미 공개된 글을 자동 삭제하지 않고 URL과 불일치 항목을 보고한다.
- 동일 상품은 기본적으로 재발행하지 않는다.

## 테스트와 완료 조건

- OAuth 콜백, 토큰 갱신, API 오류를 네트워크 모의 테스트로 검증한다.
- 글 생성 테스트에서 제목 길이, 본문 1,500~2,000자, 이미지 정확히 3장, 쿠팡 링크, `nofollow sponsored`, 가격 변동 안내, 최하단 고지와 금지 표현을 검사한다.
- 이미지 렌더링 테스트에서 세 파일의 존재, 규격, 상품 이미지 출처와 텍스트 오버플로를 검사한다.
- 게시 테스트에서 `isDraft=false`, 중복 방지, 재시도와 원격 검증을 검사한다.
- 실제 공개 전에 dry-run으로 선택 상품과 최종 HTML을 저장한다.
- 최초 실제 실행은 Gold Pick 블로그에 정확히 한 글만 공개한다.
- 공개 URL이 HTTP 200이고 제목·제품 링크·이미지 3장·모바일 약 3스크롤 분량·최하단 고지가 일치해야 완료다.

## 초기 범위에서 제외

- 하루 1회 예약 실행
- 여러 건강식품의 일괄 공개
- 직접 섭취한 것처럼 보이는 가상 체험담
- 의학적 효능 평가
- Blogger 테마 전면 개편
- AdSense 설정

## 사용자 준비 사항

구현 후 최초 연결 시 사용자는 Google Cloud Console에서 Blogger API 활성화와 데스크톱 OAuth 클라이언트 생성이 필요하다. 내려받은 OAuth 클라이언트 JSON을 안내된 로컬 경로에 두고 한 번 로그인·동의하면 이후 발행은 자동으로 진행된다.
