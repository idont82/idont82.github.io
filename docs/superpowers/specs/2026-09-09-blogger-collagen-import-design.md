# 저분자 콜라겐 글 Blogger 게시 설계

## 목표

기존 `blog/collagen-retinol-home-shopping-guide.html`을 Google Blogger에 자동 공개한다. 원본의 핵심 정보와 상품 링크를 유지하고 430px 모바일 화면에서 가로 넘침 없이 읽을 수 있게 한다.

## 콘텐츠 범위

- 제목, 요약, 선택 기준, 참고 근거와 마무리 문단을 유지한다.
- 대표 상품 영역과 상품 후보 3개의 이미지, 가격, 설명, 쿠팡 링크를 유지한다.
- 사이트 좌우 사이드바, 내비게이션, 스크립트와 고정 폭 광고 iframe은 제외한다.
- 원문 곳곳의 제휴 고지는 제거하고 표준 쿠팡 파트너스 고지를 게시물 최하단에 한 번만 배치한다.

## 레이아웃

앞서 검증한 레거시 상품 가이드 변환 구조를 재사용한다. 상품 카드는 데스크톱에서 이미지와 설명을 나란히 배치하고, 680px 이하에서는 한 열로 전환한다. 이미지에는 최대 너비 100%와 자동 높이를 적용하고 긴 상품명은 자동 줄바꿈한다. 가격은 주황색 큰 글씨로, 구매 링크는 카드 하단의 강조 버튼으로 표시한다.

## 게시 및 중복 방지

원본 URL을 기반으로 안정적인 HTML 주석 마커를 만든다. Blogger에 같은 마커가 있으면 기존 게시물을 업데이트하고, 없을 때만 새 공개 게시물을 생성한다. 원본 정적 HTML은 수정하지 않는다.

## 검증

게시 전 변환 결과에서 이미지 3개 이상, 상품 카드·가격·구매 버튼 각 3개, iframe 부재, 최하단 고지와 반응형 CSS를 검사한다. 게시 후 Blogger API 응답을 같은 기준으로 다시 검사한다. 공개 URL을 430px 폭 Chrome으로 렌더링해 제목, 이미지, 상품 카드, 가격, 버튼과 본문이 화면 밖으로 나가지 않는지 확인한다.

검증에 실패하면 게시 결과를 성공으로 보고하지 않고 원인을 확인한다. 사용자의 다른 미커밋 파일은 수정하거나 스테이징하지 않는다.
