# MBTI 64유형 한눈에 보기 설계

## 배경

`blog/mbti-16-vs-64-personality-types.html`은 16유형에 A/T와 C/S
보조축을 더해 64유형으로 확장하는 원리를 설명하지만, 현재는 전체
64유형을 비교할 수 있는 시각 자료가 없다.

이번 작업은 독자가 같은 기본 MBTI 안에서 네 확장유형의 차이를 빠르게
비교하고, 관심 있는 결과를 테스트 페이지에서 바로 확인하게 하는 데
집중한다.

## 목표

- 64개 확장유형을 하나의 16행 × 4열 표에서 비교할 수 있게 한다.
- 각 유형에 코드, 별명, 짧은 성향 설명을 제공한다.
- A/T와 C/S가 네 조합으로 갈라지는 구조를 인포그래픽으로 설명한다.
- 데스크톱과 모바일에서 표의 비교 기준을 잃지 않게 한다.
- 블로그 설명과 기존 64유형 테스트의 해석 기준을 일치시킨다.

## 정보 구조

기존 `3. 64유형은 어떤 구조로 볼 수 있을까?` 다음에 새 섹션
`4. MBTI 64유형 한눈에 보기`를 추가한다.

새 섹션은 다음 순서로 구성한다.

1. 비공식 확장 해석이라는 짧은 안내
2. `16 기본유형 × A/T × C/S = 64유형` SVG 인포그래픽
3. 네 확장조합의 의미를 설명하는 범례
4. 16행 × 4열 비교표
5. 64유형 테스트로 연결하는 CTA

기존 INTJ 비교, HEXACO 구분, 결과 해석, 테스트 섹션은 각각 5번부터
8번으로 순서를 조정한다. 사이드바 목차에는 64유형 표 바로가기를
추가한다.

## 인포그래픽

새 파일 `blog/images/mbti-64-axis-map.svg`를 만든다.

- 중앙에서 `16 기본유형`이 출발한다.
- A/T 축과 C/S 축이 결합해 A-C, A-S, T-C, T-S 네 결과로 갈라진다.
- 네 조합은 표와 동일한 색을 사용한다.
- 이미지 안의 핵심 레이블은 한국어와 영문 코드를 함께 표시한다.
- 장식보다 구조 전달을 우선하며 모바일에서도 읽을 수 있는 큰 글자를 쓴다.
- HTML에서 의미가 충분한 대체 텍스트와 캡션을 제공한다.

정확한 코드와 한글 레이블이 핵심이므로 생성형 래스터 이미지 대신
코드 기반 SVG를 사용한다. 이 선택은 확대 선명도, 접근성, 파일 크기,
문구 정확성을 보장한다.

## 64유형 표

행은 기존 테스트의 `typeCopy` 순서와 일치하는 기본 16유형으로 구성한다.
열은 A-C, A-S, T-C, T-S 순서로 고정한다.

각 셀에는 다음 정보를 표시한다.

- 전체 확장 코드, 예: `INTJ-A-C`
- 기본 유형의 기존 별명과 확장축을 결합한 짧은 별명
- 기본 유형 특성과 확장축의 행동 결을 함께 나타내는 한 문장
- `/tools/64-personality-test.html?result=<확장코드>` 링크

별명과 설명은 다음 원칙으로 만든다.

- 기본 유형의 기존 `typeCopy` 의미를 보존한다.
- A는 선택 후 비교적 덜 흔들리는 결, T는 변화와 평가에 민감하게
  대비하는 결로 쓴다.
- C는 함께 조율하는 결, S는 자기 방식과 속도를 중시하는 결로 쓴다.
- 장점이나 단점을 단정하지 않고 선호와 경향으로 표현한다.
- 질병, 능력, 적성, 직업을 진단하거나 보장하는 표현을 쓰지 않는다.
- 64개 코드는 중복 없이 정확히 한 번씩 포함한다.

## 시각 디자인

- A-C: 파란색
- A-S: 초록색
- T-C: 주황색
- T-S: 보라색
- 기본 유형 그룹: 분석가, 외교관, 관리자, 탐험가의 보조 색상

표는 기존 블로그 스타일과 어울리는 둥근 모서리, 얇은 테두리,
절제된 그림자를 사용한다. 표 머리글과 첫 번째 기본유형 열은
스크롤 중 기준을 놓치지 않게 고정한다.

## 반응형 동작

데스크톱에서는 기본유형 열과 네 확장유형 열 전체를 보여준다.

모바일에서는 표의 최소 너비를 유지하고 가로 스크롤을 제공한다.
표 위에 `좌우로 밀어 4가지 변형 비교` 안내를 표시한다. 머리글과
첫 번째 열은 고정해 현재 행과 열을 계속 확인할 수 있게 한다.
텍스트를 숨기거나 별도의 중복 모바일 표를 만들지 않는다.

## 접근성과 검색

- 표는 실제 `<table>`, `<thead>`, `<tbody>`, `<th scope>` 요소로 만든다.
- SVG는 `<img>`로 삽입하고 설명적인 `alt`와 `<figcaption>`을 제공한다.
- 색상만으로 조합을 구분하지 않고 코드와 제목을 항상 함께 표시한다.
- 링크는 키보드 포커스 상태를 제공하고 셀 전체에서 누를 수 있게 한다.
- 기존 canonical, 메타데이터, JSON-LD, 제휴 링크는 변경하지 않는다.

## 검증

- 64개 확장코드가 모두 한 번씩 존재하는지 검사한다.
- 모든 결과 링크가 해당 확장코드 쿼리를 사용하는지 검사한다.
- A-C, A-S, T-C, T-S가 각 16개씩 존재하는지 검사한다.
- HTML의 표 헤더와 접근성 속성을 검사한다.
- SVG가 올바른 XML이며 페이지에서 참조되는지 검사한다.
- 기존 JSON-LD가 계속 파싱되는지 확인한다.
- 로컬 서버에서 페이지와 SVG가 HTTP 200으로 열리는지 확인한다.
- 데스크톱과 모바일 너비에서 표와 고정 열을 시각적으로 확인한다.

## 성공 기준

- 독자가 같은 기본 MBTI의 네 확장형을 한 행에서 비교할 수 있다.
- 각 셀에서 코드, 별명, 짧은 설명을 확인할 수 있다.
- 인포그래픽만 보고도 16유형이 네 확장조합으로 나뉘는 구조를 이해할 수 있다.
- 모바일에서도 정보가 생략되지 않고 모든 64유형에 접근할 수 있다.
- 표와 테스트 결과의 기본 해석 기준이 서로 충돌하지 않는다.
