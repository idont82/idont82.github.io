# Facebook 연예인 이미지 교체 설계

## 목적

Facebook 카드뉴스에서 연예인 얼굴이 포함된 상품 이미지를 사용하지 않는다. 장원영 바람막이 게시물의 세 카드에는 인물과 브랜드 표식이 없는 자체 제작 제품 참고 이미지를 사용한다.

## 이미지 구성

같은 민트색 여성용 경량 후디 자켓을 표현한 세로형 이미지 세 장을 제작한다.

1. 행거나 마네킹에 걸린 정면 제품 사진
2. 얇은 원단과 지퍼를 보여주는 소재 디테일 사진
3. 후드와 가벼운 실루엣을 보여주는 측면 또는 접힌 제품 사진

모든 이미지에는 사람, 얼굴, 연예인 유사 인물, 브랜드 로고, 상표, 글자, 워터마크를 넣지 않는다. 특정 실제 제품의 정확한 복제라고 오인되지 않도록 일반적인 경량 후디 자켓 스타일로 표현한다.

## 저장과 선택 규칙

- 생성 이미지는 `images/facebook-card-news/`에 저장한다.
- 장원영 큐 항목에만 `cardImageUrls` 세 개를 지정한다.
- 콘텐츠 생성기는 `cardImageUrls`가 있으면 글에서 추출한 쿠팡 이미지보다 우선 사용한다.
- 다른 큐 항목은 기존 상품 이미지 추출 방식을 유지한다.
- 루트 상대 경로 이미지는 렌더러가 저장소 파일에서 직접 읽는다. 따라서 GitHub Actions 드라이런에서도 배포 전에 동작한다.

## 문구와 링크

현재 승인된 세 문구와 짧은 링크는 유지한다. 카드에는 사진과 중앙 문구만 표시하고, 해당 이미지가 실제 동일 상품 사진이라고 단정하는 문구는 추가하지 않는다. 블로그·쿠팡 목적지와 제휴 고지는 변경하지 않는다.

## 오류 처리

지정된 로컬 이미지가 없거나 열리지 않으면 같은 항목의 다음 `cardImageUrls` 후보를 시도한다. 모든 지정 이미지가 실패하면 기존 글의 상품 이미지 후보를 마지막 폴백으로 사용한다.

## 검증

- 큐 검증에서 `cardImageUrls`는 정확히 세 개의 안전한 루트 상대 이미지 경로만 허용한다.
- 콘텐츠 테스트에서 장원영 항목이 세 로컬 이미지를 순서대로 선택하는지 확인한다.
- 렌더러 테스트에서 루트 상대 경로 로딩과 후보 폴백을 확인한다.
- 실제 드라이런으로 세 PNG를 만들고 사람·얼굴·로고·텍스트가 없는지 육안 확인한다.
- 실제 Facebook 게시와 원격 푸시는 별도 승인 전 수행하지 않는다.
