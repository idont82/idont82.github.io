# Facebook 사진형 3장 카드와 단축 링크 설계

## 목적

현재 Facebook 게시물은 5장 격자에서 상품 사진이 작고 텍스트가 지나치게 많아 핵심이 잘 보이지 않는다. 새 형식은 상품 사진을 가장 중요한 시각 요소로 사용하고, 격자 미리보기에서도 읽히는 짧은 문구만 남긴다. 긴 UTM 주소는 카드 이미지에서 제거하고 사이트 내부 단축 링크로 대체한다.

## 범위

이번 변경은 Facebook 카드 콘텐츠 생성, 이미지 렌더링, 내부 단축 링크, 게시 큐의 단축 번호 매핑과 관련 테스트만 수정한다. 관리자 UI, 외부 단축 URL 서비스, 기존 Facebook 게시물 수정·삭제, Instagram 자동화는 포함하지 않는다.

기존에 게시된 `20260810-seasonal-neck-fan` 게시물은 그대로 유지한다. 새 디자인은 변경 후 생성되는 게시물부터 적용한다.

## 카드 구성

게시물 하나당 정확히 3장의 PNG를 생성한다. 모든 카드는 기존과 동일한 1080×1350 크기와 세로 비율을 유지한다.

각 카드는 다음 공통 구조를 사용한다.

- 상품 사진을 카드 전체 영역에 채운다.
- 원본 비율은 유지하되 빈 여백이 없도록 중앙 기준으로 잘라낸다.
- 카드 중앙에 반투명 검정 띠를 배치한다.
- 띠 안에는 흰색 굵은 문구를 최대 2줄로 표시한다.
- 작은 본문, 긴 설명, 전체 URL, 제휴 고지, 페이지 번호는 이미지에 넣지 않는다.
- 문구가 2줄 안에 들어오지 않으면 허용 범위까지 글꼴을 줄인다. 최소 크기에서도 넘치면 렌더링을 실패시켜 사람이 콘텐츠를 고치게 한다.

카드별 역할은 다음과 같다.

1. 관심 카드: 상품과 사용 맥락을 드러내는 짧은 제목
2. 기준 카드: 핵심 구매 기준 3개를 ` · `로 연결한 문구
3. 행동 카드: `구매 전 비교 기준 보기`와 같은 짧은 안내

자동 축약으로 의미가 달라지는 일을 막기 위해 각 큐 항목에 사람이 확인한 `cardCopy` 문자열 3개를 저장한다. 각 문자열은 공백 포함 28자 이하여야 하며 줄바꿈은 최대 하나만 허용한다. 콘텐츠 생성기는 이 문구를 임의로 다시 쓰거나 자르지 않는다. 제한을 넘기면 게시 전에 검증 오류로 중단한다.

## 상품 이미지 선택

기사 본문의 `data-coupang-link` 상품 링크 안에 있는 이미지 URL을 문서 순서대로 추출하고 중복 URL을 제거한다. 대표 `og:image`는 상품 이미지가 없을 때의 후보로 사용한다. 아바타, 광고 iframe, 사이트 로고와 본문 장식 이미지는 후보에서 제외한다.

- 이미지가 3개 이상이면 서로 다른 첫 3개를 사용한다.
- 이미지가 2개면 세 번째 카드는 첫 번째 대표 이미지를 재사용한다.
- 이미지가 1개면 세 카드 모두 그 이미지를 사용한다.
- 특정 이미지 다운로드가 실패하면 다음 후보를 사용한다.
- 모든 원격 이미지가 실패하면 렌더러의 기존 단색 기본 배경을 사용하되 문구 가독성을 유지한다.

원격 이미지는 HTTP 또는 HTTPS만 허용하고 제한 시간과 이미지 디코딩 검사를 적용한다.

## 중앙 문구 띠

중앙 띠는 카드 너비 전체에 가깝게 배치하며, 검정 배경에 충분한 투명도를 주어 상품 형태가 희미하게 보이도록 한다. 사진의 밝기나 색상과 무관하게 흰 글씨 대비가 유지되어야 한다.

- 문구는 수평·수직 중앙 정렬한다.
- 최대 2줄만 허용한다.
- 줄 간격과 내부 여백은 모바일 격자 축소 후에도 글자가 뭉치지 않도록 고정한다.
- `GOLD PICK`은 세 카드 모두 왼쪽 위에 28px 크기의 작은 브랜드 배지로 표시하며 핵심 문구보다 눈에 띄지 않게 한다.

## 내부 단축 링크

Facebook 게시글 본문에는 다음 형식의 내부 링크를 한 번만 표시한다.

```text
https://idont82.github.io/g/?n=1
```

`g/index.html`은 쿼리 매개변수 `n`을 읽어 코드에 등록된 블로그 경로로 이동하는 정적 리다이렉트 페이지다. 매핑 값은 외부 입력을 URL로 직접 사용하지 않고 코드에 저장된 허용 목록에서만 찾는다.

예시:

```text
1 → /blog/neck-fan-summer-social-guide.html
2 → /blog/wonyoung-eider-sheer-jacket-guide.html
```

실제 이동 주소에는 다음 추적값을 붙인다.

- `utm_source=facebook`
- `utm_medium=social`
- `utm_campaign=card_news`
- `utm_content=<queue item id>`

`n`이 없거나, 숫자가 아니거나, 목록에 없으면 사이트 루트 `/`로 이동한다. 임의 외부 URL, 프로토콜 상대 URL, 자바스크립트 URL은 허용하지 않는다.

## 큐 매핑

각 게시 큐 항목에 변경되지 않는 양의 정수 `shortLinkId`와 검수된 문구 3개인 `cardCopy`를 추가한다. 초기 14개 큐에는 1부터 14까지 고유한 번호를 부여한다. 이미 배정한 번호는 게시물 삭제나 순서 변경 후에도 재사용하지 않는다.

콘텐츠 생성기는 다음 두 링크를 구분한다.

- `link`: Facebook 본문에 표시하는 `/g/?n=<shortLinkId>` 주소
- `destinationLink`: 단축 페이지가 최종 이동할 UTM 또는 쿠팡 파트너스 주소

블로그 모드는 내부 블로그 목적지로 이동한다. 직접 링크 모드는 단축 페이지가 승인된 Coupang Partners HTTPS 주소로 이동할 수 있지만, 매핑은 빌드 시 고정되어야 하며 쿼리에서 목적지를 받지 않는다. 직접 링크의 `subid` 추적값은 기존 규칙을 유지한다.

## 게시글 본문

Facebook 본문은 다음 네 요소만 사용한다.

1. 짧은 제목 한 줄
2. 짧은 소개 한두 줄
3. 내부 단축 링크 한 번
4. 쿠팡 파트너스 제휴 고지

동일 링크 반복, 전체 UTM 주소, 카드 내용의 장문 반복은 넣지 않는다. 각 `shortLinkId`는 큐 전체에서 고유하고 재사용하지 않으므로, 중복 게시 탐지는 본문에 있는 전체 단축 링크 문자열을 `duplicateMarker`로 검색한다. 기존 `trackingId` 필드는 게시 이력과 분석 키로 그대로 보존한다.

## 데이터 흐름

1. 게시 큐에서 처리할 항목과 `shortLinkId`를 선택한다.
2. 기사 HTML에서 제목, 요약, 구매 기준과 상품 이미지 후보를 추출한다.
3. 콘텐츠 생성기가 3장의 짧은 문구, 이미지 URL, 단축 링크와 추적 ID를 만든다.
4. 렌더러가 각 이미지를 받아 전체 배경과 중앙 띠를 그린다.
5. 게시기는 3개 파일을 Facebook 미게시 사진으로 업로드한 뒤 하나의 게시물에 첨부한다.
6. 독자가 단축 링크를 클릭하면 `g/index.html`이 허용된 최종 목적지로 이동시킨다.

## 오류 처리

- 큐에 `shortLinkId`가 없거나 중복이면 게시 전 검증에서 실패한다.
- 큐에 `cardCopy` 3개가 없거나 문구가 28자를 넘거나 줄바꿈이 2개 이상이면 실패한다.
- 단축 링크 매핑과 큐의 ID가 일치하지 않으면 테스트와 게시가 실패한다.
- 카드 문구가 2줄에 맞지 않으면 자동으로 잘라 의미를 훼손하지 않고 명시적으로 실패한다.
- 개별 이미지 실패는 다음 후보 또는 대표 이미지 재사용으로 복구한다.
- 전체 이미지 실패는 단색 배경으로 복구한다.
- 잘못된 단축 번호는 홈페이지로 이동하며 오류 페이지나 외부 주소를 노출하지 않는다.
- 기존 게시 상태 전이, 재시도, 토큰 삭제 처리와 중복 방지는 유지한다.

## 검증 기준

자동 테스트는 다음을 보장한다.

- 콘텐츠 생성 결과가 정확히 3장이다.
- 세 카드 모두 이미지 URL 필드를 가진다.
- 각 카드 문구가 28자 이하이며 최대 2줄 제한을 만족한다.
- 렌더링 결과가 PNG 3개이며 모두 1080×1350이다.
- 중앙 띠와 최소 글꼴 크기 규칙이 적용된다.
- `data-coupang-link` 안의 상품 이미지만 선택하고 이미지 1개와 2개일 때 재사용 순서가 결정적이다.
- `/g/?n=1`부터 초기 큐 전체의 매핑이 올바른 목적지로 이어진다.
- 누락·문자·미등록 번호는 `/`로 처리된다.
- 임의 외부 리다이렉트가 불가능하다.
- Facebook 본문에는 짧은 링크가 한 번만 나오고 긴 UTM 주소가 노출되지 않는다.
- 기존 Graph API 게시, 복구, 중복 탐지 테스트가 계속 통과한다.

실제 검증에서는 새 형식의 테스트 게시물 한 건을 Gold Pick 페이지에 올려 다음을 확인한다.

- Facebook 격자에서 상품 사진이 세 카드 모두 분명히 보인다.
- 중앙 문구가 축소된 상태에서도 읽힌다.
- 카드에 긴 URL이나 장문이 없다.
- 게시글의 짧은 링크가 올바른 블로그 또는 승인된 쿠팡 주소로 이동한다.
- 제휴 고지가 게시글 본문에 보인다.
