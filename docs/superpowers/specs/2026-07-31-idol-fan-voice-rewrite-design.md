# 아이돌 상품 글 팬 시점 문체 개편 디자인

## 목표

기존 아이돌 상품 가이드 5개를 해당 연예인을 좋아하는 팬이 다른 팬에게 진심으로 추천하는 1인칭 문체로 개편한다. 검색 정보와 구매 주의사항은 유지하되 상품을 좋아하는 이유와 팬으로서 설레는 지점을 글의 앞부분에 배치한다.

## 적용 페이지

- `blog/bts-tinytan-goods-guide.html`
- `blog/seventeen-photocard-binder-guide.html`
- `blog/ive-album-photocard-guide.html`
- `blog/aespa-season-greeting-album-guide.html`
- `blog/blackpink-album-photocard-storage-guide.html`

## 문체 원칙

- 작성자는 해당 그룹을 좋아하는 팬의 1인칭 시점으로 말한다.
- “팬이라 자꾸 눈이 간다”, “책상 위에 두고 싶다”, “포토카드를 모으는 팬이라면 반가운 구성”처럼 애정과 기대를 표현한다.
- 해당 상품을 실제로 구매하거나 사용했다고 확인되지 않았으므로 “직접 샀다”, “써보니”, “배송받았다” 같은 체험담은 쓰지 않는다.
- 팬 커뮤니티 은어를 과하게 사용하지 않고 처음 읽는 사람도 이해할 수 있는 정보형 문장을 유지한다.
- 상품을 무조건 좋다고 단정하지 않는다. 추천 이유 다음에 옵션, 공식성, 랜덤 구성, 가격 변동 등 확인 사항을 자연스럽게 안내한다.

## 페이지별 팬 관점

### BTS

타이니탄 캐릭터를 일상에서 자주 보고 싶은 팬의 관점으로 쓴다. 멤버 옵션을 고르는 즐거움과 문구·마우스를 책상에서 사용할 때의 만족을 중심으로 추천한다.

### 세븐틴

멤버별 포토카드가 늘어날수록 정리 자체가 팬 활동의 즐거움이 된다는 관점으로 쓴다. 카드를 한눈에 넘겨보는 만족과 슬리브·바인더 규격의 중요성을 연결한다.

### 아이브

앨범 콘셉트와 포토카드 구성을 기다리는 팬의 관점으로 쓴다. 여러 버전을 모으는 설렘을 표현하되 랜덤 구성과 판매처 특전을 차분히 구분한다.

### 에스파

세계관과 콘셉트 사진을 좋아하는 팬의 관점으로 시즌그리팅과 앨범을 비교한다. 구성품을 펼쳐보는 기대감과 고가 상품의 실사용·보관 부담을 함께 설명한다.

### 블랙핑크

앨범과 멤버별 포토카드를 오래 깨끗하게 간직하고 싶은 팬의 관점으로 쓴다. 카드를 정리하며 다시 보는 즐거움과 슬리브·바인더 보관 기준을 연결한다.

## 수정 범위

원본 데이터 `data/idol-shopping-blog-pages.json`에서 `intro`, `summary`, `lead`, 비교 카드 설명, 상품 추천 이유, 주의문, FAQ 답변을 팬 시점으로 수정한다. 생성기 구조, 상품 URL, 가격, 검색 순위, SEO 제목, canonical URL과 구조화 데이터는 유지한다.

## 검증

`tests/idol-shopping-blog-pages.test.js`에 다음 검사를 추가한다.

- 모든 글에 팬임을 드러내는 1인칭 문구가 존재한다.
- “좋아해서”, “설렌다”, “마음에 든다”처럼 추천 감정이 드러난다.
- 각 상품에 팬 관점의 추천 이유가 있다.
- “직접 구매했다”, “써보니”, “배송받았다” 같은 검증되지 않은 체험 표현이 없다.
- 기존 SEO, 제휴 고지, 공식성 주의문과 발견성 검사가 계속 통과한다.
