# 기존 블로그 글 3개 Blogger 게시 설계

## 목표

기존 Gold Pick 정적 블로그 글 세 개를 Google Blogger에 자동 공개한다. 원본 글의 핵심 정보와 쿠팡 상품 링크를 유지하면서, 430px 모바일 화면에서 가로 스크롤 없이 읽을 수 있게 변환한다.

## 게시 대상

1. `blog/highest-performance-laptop-top3-guide.html`
2. `blog/document-work-laptop-top3-guide.html`
3. `blog/lactofit-probiotics-home-shopping-guide.html`

이미 게시된 `best-value-laptop-top3-guide.html`은 대상에서 제외한다.

## 변환 방식

### 노트북 글

현재 검증된 Blogger 노트북 레이아웃을 재사용한다. 상품 카드 3개, 강조 가격 3개, 구매 버튼 3개를 유지한다. 모바일에서는 상품 카드를 한 열로 전환하고 비교표의 최소 너비를 해제해 세 열이 화면 안에서 줄바꿈되도록 한다.

### 락토핏 글

본문의 제목, 설명, 상품 이미지, 선택 기준, 제품 후보와 구매 링크를 유지한다. Blogger에서 불필요한 사이트 내비게이션, 사이드 영역, 고정 폭 광고 iframe과 스크립트는 제외한다. 기존 상품 영역은 모바일 한 열 카드로 표시하며 이미지와 텍스트는 컨테이너 너비를 넘지 않게 한다.

본문 곳곳의 쿠팡 고지 문구는 제거하고, 게시물 최하단에 다음 문구를 한 번만 배치한다.

> 이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

## 게시 및 중복 방지

각 게시물에 원본 URL 기반의 안정적인 HTML 주석 마커를 넣는다. Blogger에서 같은 마커를 가진 게시물이 발견되면 새 글을 만들지 않고 해당 글을 업데이트한다. 마커가 없을 때만 새 공개 게시물을 생성한다.

## 모바일 규칙

- 전체 본문 너비는 Blogger 콘텐츠 영역 안으로 제한한다.
- 이미지와 미디어는 `max-width:100%`와 자동 높이를 사용한다.
- 상품 카드와 다단 레이아웃은 680px 이하에서 한 열로 전환한다.
- 비교표는 모바일에서 최소 너비를 제거하고 긴 텍스트를 줄바꿈한다.
- 링크와 버튼은 화면 밖으로 나가지 않으며 손가락으로 누르기 충분한 여백을 둔다.
- 고정 폭 iframe은 게시물에서 제거한다.

## 검증

게시 전 자동 테스트에서 제목, 원본 마커, 이미지, 상품 링크, 최하단 고지와 모바일 CSS를 검사한다. 게시 후 Blogger API로 반환된 본문을 다시 검사한다. 각 공개 URL을 430px 폭 Chrome으로 렌더링해 가로 넘침, 이미지 크기, 표와 카드 배치, 하단 고지를 확인한다.

한 게시물의 변환이나 원격 검증이 실패하면 해당 오류를 보고하고 다음 게시물을 무조건 성공으로 처리하지 않는다. 원본 정적 블로그 파일과 사용자의 다른 미커밋 파일은 수정하지 않는다.
