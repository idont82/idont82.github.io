# 네이버 검색 CTR 개선 설계

## 배경

2026년 7월 22일부터 28일까지 네이버 검색 실적은 노출 4,321회,
클릭 226회, CTR 5.2%다. 이전 7일보다 노출은 12.6% 증가했지만
클릭은 2.7% 증가했고 CTR은 0.5%p 하락했다.

이번 작업은 노출이 이미 발생하는 페이지의 검색 의도를 분명히 하고,
서로 유사한 서울 인형뽑기 페이지의 역할을 분리하는 데 집중한다.

## 목표

- 고노출·저CTR 페이지가 검색 결과에서 제공하는 정보를 구체화한다.
- 서울 인형뽑기 메인 가이드와 블로그 코스 글의 검색 의도를 분리한다.
- 소금빵 페이지가 `소금빵 재료` 검색 의도에 직접 답하도록 개선한다.
- 기존 URL, 레이아웃, 구조화 데이터의 유효성을 유지한다.

## 변경 범위

### 서울 인형뽑기 블로그

대상: `blog/seoul-claw-machine-guide.html`

- 주제를 서울 전체 매장 총정리에서 `서울 인형뽑기 반나절 코스`로 좁힌다.
- 제목, 설명, H1, 도입부에서 이동 순서와 소요시간을 명확히 한다.
- 상세 지도와 전체 매장 정보는 `claw-machine-guide.html`의 역할로 남긴다.
- 기존 지역별 코스와 내부 링크는 유지한다.

### 캡슐세제 비교

대상: `search/capsule-detergent-budget-top3.html`

- 제목과 설명에 실제 비교 기준인 1회 세탁 가격, 세척력,
  드럼·통돌이 적합성을 반영한다.
- 본문 상단에서 용도별 추천 결론을 빠르게 확인할 수 있게 한다.
- 기존 TOP 3 제품과 비교 근거는 바꾸지 않는다.

### 강남 인형뽑기 가이드

대상: `search/gangnam-claw-machine-guide.html`

- 현재 핵심 제목인 `강남 인형뽑기 성지`는 유지한다.
- 검색 설명과 도입부에서 강남역 출구, 10곳, 추천 동선과
  예상 소요시간을 구체적으로 안내한다.
- 서울 전체 가이드가 아닌 강남 현장 동선 페이지라는 역할을 강조한다.

### 소금빵 레시피

대상: `recipe/salt-bread.html`

- 제목과 H1에 `소금빵 재료`를 반영한다.
- 본문 상단에서 필수 재료와 중량을 바로 확인할 수 있게 한다.
- 기존 조리 순서와 제휴 링크는 유지한다.

## 제외 범위

- 페이지 URL 변경, 리디렉션, canonical 변경
- 디자인과 공통 CSS 변경
- `index.html` 및 `sitemap.xml` 변경
- 신규 페이지 생성
- 현재 작업 트리에 남아 있는 다른 블로그·데이터·스크립트 변경

## 검증

- 네 파일의 title, description, H1이 각각의 목표 검색 의도와 일치하는지 확인한다.
- canonical과 기존 내부 링크가 유지되는지 확인한다.
- HTML 태그 중첩과 JSON-LD 구문을 점검한다.
- 로컬 서버에서 네 페이지가 모두 HTTP 200으로 열리는지 확인한다.
- 수정된 파일만 diff로 검토해 기존 작업과 섞이지 않았는지 확인한다.

## 성공 기준

- 서울 블로그 글이 `반나절 코스`, 메인 가이드가 `전체 지역·매장 정보`를 담당한다.
- 캡슐세제 페이지 첫 화면에서 비교 기준과 용도별 결론을 확인할 수 있다.
- 강남 페이지 첫 화면에서 출발점, 매장 수, 동선을 확인할 수 있다.
- 소금빵 페이지 첫 화면에서 핵심 재료와 중량을 확인할 수 있다.
- 기존 URL과 페이지 레이아웃이 유지된다.
