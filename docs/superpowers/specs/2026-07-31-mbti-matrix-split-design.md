# MBTI 64유형 표 분할 설계

## 목표

`blog/mbti-16-vs-64-personality-types.html`의 64유형 비교표에서 내부 가로·세로 스크롤을 제거하고, 본문 너비 안에서 모든 내용을 읽을 수 있게 한다.

## 레이아웃

- 기존 5열 표 하나를 3열 표 두 개로 분리한다.
- 첫 번째 표는 `기본유형`, `A-C`, `A-S` 열을 표시한다.
- 두 번째 표는 `기본유형`, `T-C`, `T-S` 열을 표시한다.
- 두 표 모두 16개 기본유형 전체를 순서대로 표시한다.
- 두 번째 표 위에 짧은 제목을 두어 A 계열과 T 계열의 구분을 명확히 한다.
- 표 컨테이너의 `max-height`와 `overflow` 스크롤을 제거한다.
- 표는 컨테이너 너비를 100% 사용하며 최소 너비를 강제하지 않는다.

## 보존 사항

- 64개 결과 링크, 유형명, 설명 문구와 색상 체계를 그대로 유지한다.
- 각 표는 독립적인 `caption`과 접근성 레이블을 갖는다.
- 데스크톱과 모바일 모두 페이지 또는 표 내부에 가로 스크롤이 생기지 않아야 한다.
- 모바일에서는 글자와 셀 여백을 줄이되 유형 설명을 숨기지 않는다.

## 검증

- 정적 테스트에서 2개의 표, 각 표의 16개 행과 32개 결과 링크를 확인한다.
- CSS 테스트에서 스크롤 속성과 강제 최소 너비가 제거됐는지 확인한다.
- 로컬 서버에서 데스크톱 및 390px 모바일 너비로 페이지 오버플로와 표 내부 오버플로가 없는지 확인한다.
