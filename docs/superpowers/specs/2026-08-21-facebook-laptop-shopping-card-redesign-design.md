# 페이스북 노트북 쇼핑 카드 재설계

## 목표

기존 노트북 페이스북 카드의 반복 이미지와 일반적인 문구를 개선한다. 사용자가 피드를 스크롤하는 첫 순간에 가격, GPU 또는 필수 사양을 알아볼 수 있는 쇼핑형 카드로 가성비·최고성능·문서용 게시물 세 건을 교체한다.

## 확정한 시각 방향

참고 이미지의 정보 구조만 활용하고 Gold Pick 전용 원본 레이아웃을 만든다. 카드 왼쪽 약 3분의 2에는 큰 후킹 요소와 실제 제품 사진을 배치하고, 오른쪽 약 3분의 1은 핵심 스펙과 추천 용도를 두 구역으로 나눈다.

- 가성비: 현재 가격대를 가장 큰 후킹 요소로 사용한다.
- 최고성능: GPU 등급을 가장 큰 후킹 요소로 사용하고 가격은 보조 정보로 내린다.
- 문서용: 현재 가격대와 Windows·메모리·저장공간 같은 필수 사양을 함께 강조한다.
- 모든 카드에는 작은 Gold Pick 브랜드 배지를 둔다.
- 가격이 있는 카드에는 `작성일 기준 · 가격 변동 가능`을 표시한다.
- 참고 게시물의 로고, 문구, 구성 요소를 그대로 복제하지 않는다.

## 카드 구성

게시물 한 건은 카드 세 장으로 구성하며 추천 제품 한 대당 카드 한 장을 사용한다. 같은 제품 사진을 반복하지 않고 각 카드에 해당 제품의 실제 사진을 표시한다.

각 카드에는 다음 정보만 넣는다.

1. 큰 후킹 요소: 가격대, GPU 또는 필수 사양
2. 짧은 제품 식별 정보
3. 핵심 스펙 최대 세 개
4. 추천 용도 최대 네 개
5. 가격 기준일 또는 옵션 확인 주의 문구

모든 본문과 라벨은 모바일 피드에서도 읽을 수 있도록 짧게 유지한다. 카드의 핵심 문구는 이미지 가장자리와 페이스북 갤러리 크롭 영역을 피한다.

## 데이터와 렌더링 구조

기존 일반 카드 렌더링은 유지하고 교체 전용 큐 `data/facebook-laptop-shopping-post-queue.json`에만 쇼핑형 템플릿을 사용한다. 기존 게시 이력이 든 큐는 수정하지 않는다. 교체 큐의 각 항목에는 `cardTemplate: "shopping-grid"`와 정확히 세 개인 `shoppingCards` 배열을 둔다. 각 쇼핑 카드가 다음 값을 직접 제공해 렌더러가 화면 문구를 추측하지 않게 한다.

- 템플릿 종류
- 큰 후킹 문구
- 제품 이미지
- 제품명 축약 문구
- 핵심 스펙 목록
- 추천 용도 목록
- 가격·옵션 주의 문구

교체 큐는 새 단축 링크 ID 18, 19, 20을 순서대로 사용한다. 각 항목은 삭제 대상인 기존 게시 ID를 `replacesFacebookPostId`로 한 개씩 보관한다. 삭제 허용 대상은 다음 세 개뿐이다.

- `1243431898854300_122110686801428837`
- `1243431898854300_122110687095428837`
- `1243431898854300_122110687353428837`

렌더러는 1080×1350 PNG 세 장과 기존 형식의 매니페스트를 생성한다. 쇼핑형 데이터가 누락되거나 목록 개수가 기준을 넘으면 이미지를 만들기 전에 실패해야 한다. 기존 카드 큐와 직접 링크 게시물의 동작은 변경하지 않는다.

## 페이스북 본문

블로그 단축 링크는 계속 본문의 첫 줄에 둔다. 그 아래에 짧은 소개와 제휴 고지를 배치한다. 이미지 안의 가격은 클릭을 유도하는 참고 정보이고, 최종 가격과 옵션은 블로그 및 판매 페이지에서 다시 확인하도록 안내한다.

## 교체 절차

기존 게시물은 게시 후 이미지를 교체할 수 없으므로 새 게시물로 대체한다.

1. 세 카테고리의 쇼핑형 카드 아홉 장을 로컬에서 생성한다.
2. 데스크톱 원본과 축소된 모바일 크기에서 문구, 이미지, 가격 주의 문구를 확인한다.
3. 드라이런으로 세 게시물의 카드 수와 본문 첫 줄 링크를 확인한다.
4. 새 게시물 세 건을 가성비 → 최고성능 → 문서용 순으로 게시한다.
5. Graph API로 각 새 게시물의 카드 세 장, 첫 줄 링크, 고유 링크를 확인한다.
6. 새 게시물 세 건이 모두 확인된 뒤 교체 큐의 `replacesFacebookPostId` 세 건을 삭제한다.
7. 새 게시 ID, 고유 링크, 게시 시각을 큐에 기록하고 원격 `main`에 반영한다.

새 게시 중 하나라도 실패하면 이후 게시와 기존 게시물 삭제를 중단한다. 새 게시물 확인 전에는 기존 게시물을 삭제하지 않는다. 삭제 명령은 교체 큐 세 항목이 모두 `published`이고 Graph API 검증 결과가 모두 성공했을 때만 실행한다. 삭제 대상은 위의 기존 노트북 게시물 ID 세 개로 고정하며 다른 Gold Pick 게시물에는 영향을 주지 않는다.

## 검증 기준

- 각 게시물에 1080×1350 카드가 정확히 세 장 있다.
- 게시물 안의 세 제품 이미지가 서로 다르다.
- 큰 후킹 요소와 핵심 스펙이 모바일 축소 화면에서도 읽힌다.
- 가격 카드마다 변동 가능 고지가 있다.
- 최고성능 카드에는 옵션별 GPU·가격 확인 주의가 있다.
- 게시물 본문의 첫 줄이 각각 새 단축 링크 18, 19, 20과 일치한다.
- 제휴 고지가 유지된다.
- 기존 일반 카드 렌더링 테스트가 계속 통과한다.
- 새 게시물 세 건을 확인하기 전에는 기존 게시물이 남아 있다.
- 교체 후 기존 게시물 세 건만 삭제되고 새 게시물 세 건은 접근 가능하다.

## 범위 제외

- 블로그 본문이나 추천 상품 아홉 개의 재선정
- 노트북 이외의 기존 페이스북 카드 재설계
- 게시물 성과 측정 방식 변경
- 가격 자동 갱신 또는 실시간 가격 표시
