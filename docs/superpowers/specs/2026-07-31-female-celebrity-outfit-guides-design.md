# 여자 연예인 실착 상품 팬 시점 블로그 2종 설계

## 목표

여자 연예인이 실제로 착용한 옷 가운데 2026년 7월 31일 기준 쿠팡에서 동일 품번으로 판매되는 상품 2개를 소개한다. 글쓴이는 해당 연예인의 팬이라는 관점에서 착장에 끌린 이유를 자연스럽게 설명하되, 실착 사실과 상품 동일성은 출처와 품번으로 객관적으로 검증한다.

## 대상 글

### 수지 K2 여름 셔츠

- 연예인: 수지
- 브랜드: K2
- 제품명: 시원서커 DRY ICE 반팔 셔츠 W
- 품번: `KWM26452`
- 핵심 검색 의도: 수지 착용 셔츠의 정확한 제품명, 품번, 특징, 사이즈와 현재 쿠팡 판매 정보 확인
- 제목 방향: `수지 K2 반팔 셔츠 KWM26452 착용 정보 | 사이즈·소재·쿠팡 가격`

### 장원영 아이더 경량 자켓

- 연예인: 장원영
- 브랜드: 아이더
- 제품명: SHEER(시어) 여성 경량 후디 자켓
- 품번: `DWM26154`
- 핵심 검색 의도: 장원영 착용 바람막이의 정확한 제품명, 품번, 색상, 사이즈와 현재 쿠팡 판매 정보 확인
- 제목 방향: `장원영 아이더 시어 자켓 DWM26154 착용 정보 | 색상·사이즈·쿠팡 가격`

## 사실 검증 기준

각 글은 다음 조건을 모두 만족해야 한다.

1. 브랜드 공식몰 또는 신뢰할 수 있는 유통사의 상품 페이지에서 연예인 착용 사실을 확인한다.
2. 출처에 표시된 제품 품번과 쿠팡 상품명의 품번이 일치해야 한다.
3. 색상별 접미 품번이 확인되는 경우 기본 품번과 색상 옵션을 구분해 표시한다.
4. 쿠팡 파트너스 API가 제공하는 가격과 검색 순서는 2026년 7월 31일 확인값으로 기록한다.
5. 쿠팡 검색 순서는 판매량 순위로 표현하지 않고, 해당 검색어의 API 결과 노출 순서라고 설명한다.
6. 공식 판매가와 쿠팡 가격이 다르면 어느 한쪽을 정상 가격처럼 단정하지 않고 판매처·옵션별 변동 가능성을 알린다.

## 글의 목소리

도입부와 제품 선택 이유는 팬의 1인칭 시점으로 작성한다. 팬심을 과장된 구매 권유로 연결하지 않고 다음 원칙을 지킨다.

- “화보에서 보고 같은 옷이 궁금해 품번까지 찾아봤다”는 탐색 과정을 보여준다.
- 연예인의 외모나 체형을 독자의 구매 기준으로 삼지 않는다.
- “무조건 사야 한다”, “따라 입으면 같은 분위기가 난다” 같은 단정은 사용하지 않는다.
- 실제 제품의 핏과 기능, 가격을 확인한 뒤 팬으로서 마음에 든 지점을 구체적으로 설명한다.
- 구매 여부는 사이즈, 활용도, 공식 판매가와 쿠팡 가격을 비교한 뒤 결정하도록 안내한다.

## 페이지 구성

두 글은 기존 아이돌 쇼핑 가이드의 블로그 셸과 광고 구조를 재사용한다.

1. 헤더
   - 연예인명, 브랜드, 정확한 품번이 드러나는 제목
   - 팬 시점의 짧은 소개 문장
2. 핵심 요약
   - 연예인 착용 확인
   - 동일 품번 확인
   - 가격 확인일
3. 팬의 착장 이야기
   - 착장을 처음 본 인상
   - 같은 제품을 찾게 된 이유
4. 동일 제품 확인표
   - 연예인
   - 브랜드
   - 제품명
   - 기본 품번
   - 쿠팡 상품명에 표시된 품번
   - 확인 결과
5. 제품 특징
   - 소재와 기능
   - 실루엣과 활용 계절
   - 공식 사이즈 정보
6. 팬이 마음에 든 이유
   - 실제 디자인과 활용도를 근거로 3개 항목 정리
7. 구매 전 확인사항
   - 색상과 사이즈 재고
   - 판매자와 정품 표기
   - 공식 판매가와 쿠팡 가격 비교
   - 교환·반품 조건
8. 쿠팡 동일 상품 카드
   - API 제공 상품 이미지, 상품명, 확인 가격, 제휴 링크
   - 쿠팡 파트너스 수수료 고지
9. 출처와 FAQ
   - 착용 근거와 공식 제품 페이지
   - 동일 제품 판별법, 가격 차이, 사이즈 선택에 관한 질문
10. 우측 추천 영역
   - 기존 300×250 쿠팡 추천 카드 유지

## 이미지 정책

- 연예인 사진과 화보 이미지를 저장하거나 복제하지 않는다.
- 쿠팡 파트너스 API가 제공한 해당 상품 이미지를 대표 이미지와 상품 카드에 사용한다.
- 이미지 대체 텍스트에는 연예인 이름보다 브랜드, 제품명, 품번을 우선 기재한다.
- 대표 이미지가 외부 URL이므로 로딩 실패 시에도 제품명과 핵심 정보가 보이도록 텍스트 구조를 유지한다.

## 데이터와 생성 구조

- 신규 JSON 데이터 파일에 두 페이지의 문구, 검증 정보, 출처, 제품 정보를 저장한다.
- 신규 생성 스크립트가 JSON을 읽어 두 HTML 파일을 만든다.
- 생성 결과는 기존 `/blog/assets/style.css`와 `/blog/assets/blog.js`를 사용한다.
- 두 URL을 `index.html`과 `sitemap.xml`에 추가한다.
- 기존 사용자의 스테이징 및 수정 파일은 덮어쓰지 않고 필요한 부분만 병합한다.

## 오류 및 변경 대응

- 쿠팡 상품이 품절되거나 가격이 바뀔 수 있음을 본문과 상품 카드에 표시한다.
- 품번이 없는 쿠팡 상품은 동일 제품 후보에서 제외한다.
- 생성 시 필수 출처, 품번, 제휴 링크 또는 이미지가 누락되면 실패하도록 검증한다.
- 쿠팡 가격은 정적 확인값임을 표시하고 실시간 가격으로 오인할 문구를 사용하지 않는다.

## 검증

- 먼저 두 페이지에 필요한 필수 문구와 구조를 검사하는 Node 테스트를 작성하고 실패를 확인한다.
- 생성 스크립트와 데이터를 구현한 뒤 테스트를 통과시킨다.
- 생성 스크립트를 다시 실행해도 결과가 동일한지 확인한다.
- `index.html`과 `sitemap.xml`에 두 URL이 각각 한 번만 들어가는지 확인한다.
- 로컬 서버에서 두 페이지가 HTTP 200으로 열리는지 확인한다.
- 데스크톱과 모바일 너비에서 본문, 상품 표, 우측 추천 카드가 넘치거나 가로 스크롤을 만들지 않는지 확인한다.

## 완료 기준

- 서로 다른 여자 연예인의 실착 상품 글 2개가 생성된다.
- 각 글에 정확한 기본 품번, 실착 출처, 쿠팡 동일 품번 상품과 가격 확인일이 표시된다.
- 팬의 1인칭 애정이 느껴지면서도 확인되지 않은 사실이나 동일 제품 주장이 없다.
- 광고·제휴 고지와 가격 변동 안내가 눈에 보인다.
- 기존 블로그 레이아웃과 모바일 반응형 동작을 유지한다.
