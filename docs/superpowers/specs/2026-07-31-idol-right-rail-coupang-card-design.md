# 아이돌 글 우측 쿠팡 추천 카드 디자인

## 문제

아이돌 상품 글의 우측 사이드바에는 관련 글과 구매 전 확인만 있고, 기존 블로그 글에서 사용하는 쿠팡 추천 배너가 생성되지 않는다.

## 수정 방식

- `scripts/generate-idol-shopping-blog-pages.js`의 우측 사이드바 최상단에 쿠팡 300×250 추천 배너를 추가한다.
- 기존 글과 동일한 위젯 ID `989908`, `template=carousel`, 추적 코드 `AF7523287`을 사용한다.
- 우측 스택에 `blog-stack-sticky`를 적용한다.
- 배너 제목은 `추천 배너`로 표시한다.
- 배너 바로 아래에 쿠팡 파트너스 수수료 고지를 표시한다.
- 기존 관련 글과 구매 전 확인 패널은 배너 아래에 그대로 유지한다.
- 모바일은 기존 `mobile-top-ad`를 사용하고 우측 레일의 반응형 동작은 공통 블로그 CSS를 따른다.

## 검증

- 다섯 페이지의 우측 사이드바에 `blog-stack-sticky`가 있어야 한다.
- 위젯 ID `989908`을 사용하는 300×250 `blog-ad-frame`이 있어야 한다.
- 우측 배너에 제휴 고지가 있어야 한다.
- 기존 팬 문체, 상품 표, SEO와 발견성 테스트가 계속 통과해야 한다.
